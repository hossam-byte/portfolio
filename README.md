## 🚀 Getting Started Locally

This is a lightweight, pure web portfolio that runs directly on any modern browser or local web server:

### Using PHP Built-in Server:
```bash
php -S localhost:8000
```
Then open `http://localhost:8000` in your web browser.

### Using Laragon / Apache / Nginx:
Place the repository folder into your web root (e.g. `c:/laragon/www/Portfolio`) and visit:
`http://localhost/Portfolio/`
